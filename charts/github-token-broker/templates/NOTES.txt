1. Get the broker service:

   kubectl get svc -n {{ .Release.Namespace }} {{ include "github-token-broker.fullname" . }}

2. Call the token endpoint from a workload in an allowed namespace:

   curl -sS -X POST http://{{ include "github-token-broker.fullname" . }}.{{ .Release.Namespace }}.svc/v1/token \
     -H "Authorization: Bearer $(cat /var/run/secrets/kubernetes.io/serviceaccount/token)" \
     -H 'content-type: application/json' \
     -d '{"repo":"example-org/example-repo","permissions":{"contents":"read"}}'

3. The App private key must be provided by the Secret
   {{ .Values.github.credentialsSecret.name | quote }} (key
   {{ .Values.github.credentialsSecret.key | quote }}, normally synced by
   External Secrets from GCP Secret Manager).
